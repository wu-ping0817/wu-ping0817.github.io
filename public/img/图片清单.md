# 图片资源清单（person_show）

所有图片统一放在 `public/img/` 下，由你自行准备后直接放入即可，**无需改动代码**。
代码通过 `ImageSlot` 组件按下方文件名引用（路径前缀 `img/`）。

> 命名规范：小写字母 + 连字符；替换时保持文件名一致即可。
> **已优化（本轮）**：原首页 Hero 主视觉大图（`hero-visual.webp`）已**移除**，改由代码驱动的背景动画（`src/components/HeroBackdrop.vue`）生成，无需任何静态图片；社交分享图（`og-cover.webp`）也从必需项移除。整体静态图片数量大幅减少。

## 已由代码动画替代（无需静态图片）
- **首页 Hero 背景**：由 `src/components/HeroBackdrop.vue` 的流动光晕 + 几何网格动画呈现（主题色，暗/亮自适应，尊重 `prefers-reduced-motion`）。

## 使用与替换说明
- **作品封面 / 设计作品未提供图片时**，页面自动显示「代码生成的渐变 + 标题视觉块」，布局稳定、视觉统一，**不强制必须提供图片**。
- 放入对应文件并刷新即显示真实图片：封面用 `works/<id>.webp`，设计作品用 `design-01.webp`…（与 `data/portfolio.json` 的 `id` 对应）。
- `public/favicon.svg` 为站点图标（矢量，保留，可直接替换）。

## 新增作品
在 `data/portfolio.json` 的 `items` 追加一项（含 `id` / `category` / `thumb`），并把缩略图命名为 `works/<id>.webp` 放入 `public/img/works/`。
