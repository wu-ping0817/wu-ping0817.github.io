# person_show · 双主题配色标准（正式设计标准）

> 版本：v1.0（定稿）
> 关联文档：需求文档 v0.3、设计文档 v1.0（M8 主题样式系统）
> 品牌双色：**主色 #fefcff（近白）** · **辅色 #b6d4f6（淡蓝）**
> 适用范围：全部前端界面与组件（M1–M4 展示层、M7 动画、M8 主题）

---

## 1. 目的与范围

将双主题配色**正式定稿为设计标准**，明确两种品牌色的角色分工、适用场景与可读性约束，并落实到组件主题令牌（`src/styles/theme.css` + `src/theme/tokens.js`）。后续所有界面与组件**必须**引用令牌变量，**禁止**硬编码色值，确保视觉风格统一、明暗对比与可读性符合 WCAG AA 规范。

---

## 2. 品牌双色定义

| 角色 | 色值 | 名称 | 设计语义 |
|---|---|---|---|
| **主色 Primary** | `#fefcff` | 近白 | 主视觉基座、焦点留白、亮色主题下的页面画布；暗色主题下转为主体前景文字 |
| **辅色 Secondary** | `#b6d4f6` | 淡蓝 | 背景与内容承载区、主操作填充、强调面；暗色主题下转为强调色（链接/焦点/高亮） |

> 两色为**品牌身份色**，不可替换。其余色值（文字墨色、深底、边框等）为「派生中性色」，仅用于保障可读性，可随主题微调。

---

## 3. 角色分工与适用场景

按用户确认的职责划分，并结合双主题可切换特性，明确如下：

### 3.1 通用职责（两种主题一致）

| 职责 | 承担色 | 说明 |
|---|---|---|
| **关键操作（主按钮 / CTA）** | 辅色 `#b6d4f6` 为填充 | 可点击信号；其上文字用深墨 `#0c1626`（见 6.2 反模式） |
| **视觉焦点 / 强调元素** | 主色用于"留白聚焦"，辅色用于"色块强调" | 主色提供干净焦点基底，辅色块承载强调信息 |
| **背景 / 内容区域** | 辅色 `#b6d4f6` | 内容卡片、面板、Hero 副区、导航底栏等大面积背景 |
| **页面主画布** | 主色 `#fefcff` | 亮色主题页面底色（明亮、干净的视觉焦点） |

### 3.2 主题适配映射（同一品牌色在两主题中的功能切换）

双主题下，两色**功能互换**以保持各自最佳对比：

| 元素 | 亮色主题 | 暗色主题 |
|---|---|---|
| 主色 `#fefcff` | 页面主画布（背景） | 前景文字 / 强调文字 |
| 辅色 `#b6d4f6` | 内容区背景 / 主操作填充 | 强调色（链接 / 焦点环 / 主操作填充） |
| 正文文字 | 深墨 `#16233b` | 近白 `#fefcff`（即主色） |
| 页面底色 | 主色近白 | 派生深墨蓝 `#0e1726` |

> 设计要点：亮色主题"以白为底、以蓝为面"；暗色主题"以蓝为光、以深为底"。两品牌色始终在场，风格统一。

### 3.3 典型场景取色

| 场景 | 亮色主题 | 暗色主题 |
|---|---|---|
| 首屏 Hero 画布 | `bg-base`（主色近白） | `bg-base`（深墨蓝） |
| Hero 强调块 / 标语底 | `bg-surface`（辅色淡蓝）+ 深墨字 | `accent`（辅色淡蓝）+ 深墨字 |
| 文章/作品卡片 | `bg-surface`（辅色）+ 深墨字 | `bg-surface`（深卡）+ 近白字 |
| 主操作按钮 | `accent`（辅色）填充 + 深墨字 | `accent`（辅色）填充 + 深墨字 |
| 链接 | `link` `#25518a` | `link` `#9cc6f2` |
| 焦点态 | 2px `focus` `#6fa8e8` 描边 | 2px `focus` `#8fc0f5` 描边 |
| 分区分隔 / hover | `bg-subtle` 浅蓝灰 | `bg-subtle` 深蓝灰 |

## 5. 派生中性色说明

品牌双色均为高明度浅色，**无法直接承担正文文字**（近白压淡蓝仅 1.50:1，严重不达标）。因此引入派生中性色，仅服务于可读性，不属于品牌色：

- **深墨系** `#0c1626` / `#16233b` / `#4a5b73`：亮色主题的正文与压辅色文字。
- **深底系** `#0e1726` / `#152033` / `#16263f`：暗色主题的页面与卡片背景。
- 这些中性色保持"冷调偏蓝"，与品牌淡蓝同源，确保整体色调统一。

## 6. 应用规则与反模式

### 6.1 必须遵守

1. 所有界面/组件只用 `var(--color-*)` 令牌，**禁止**在样式中写死 `#fefcff` / `#b6d4f6` 等具体色值（除令牌定义文件本身）。
2. 主题切换仅改 `<html data-theme>`，组件不感知具体色值。
3. 主操作按钮填充用 `--color-accent`（辅色），其上文字**必须**用 `--color-text-on-accent`（深墨）。
4. 文字颜色必须与背景令牌配对使用（见第 4 章映射），不得跨配对使用。

### 6.2 反模式（禁止）

| ❌ 禁止 | 原因 |
|---|---|
| 近白 `#fefcff` 文字直接压在淡蓝 `#b6d4f6` 上 | 对比度 1.50:1，严重不达标 |
| 在辅色面上用主色白字做按钮 | 同上，不可读 |
| 暗色主题把近白当背景、淡蓝当文字 | 淡蓝 on 近白对比不足，且违背"蓝为光、深为底" |
| 组件内硬编码色值（如 `color:#b6d4f6`） | 破坏主题一致性与可维护性 |
| 仅用主色白 + 辅色蓝两色铺满全站无中性墨 | 无正文可读性 |

## 7. 落地规范（组件主题定义）

- **令牌文件**：`src/styles/theme.css`（CSS 变量，含 `:root`/light/dark 三套）；`src/theme/tokens.js`（同语义的 JS 镜像，供动画/Canvas/图表取色）。
- **引入**：在 `src/main.js` 或 `App.vue` 顶部 `import './styles/theme.css';`。
- **切换**：`ThemeToggle` 组件写 `document.documentElement.dataset.theme` 并持久化 `localStorage`，颜色经 `--theme-transition` 平滑过渡。
- **组件引用示例**：

  ```css
  .btn-primary {
    background: var(--color-accent);        /* 辅色填充 = 关键操作 */
    color: var(--color-text-on-accent);     /* 深墨字，AA 达标 */
  }
  .card {
    background: var(--color-bg-surface);    /* 辅色内容区 */
    color: var(--color-text-on-accent);
  }
  .page {
    background: var(--color-bg-base);       /* 主色画布 */
  }
  a { color: var(--color-link); }
  :focus-visible { outline: 2px solid var(--color-focus); }
  ```

---

## 8. 验收标准

- **对比度**：全部文字/背景组合 ≥ WCAG AA（已核验，见第 4 章）。
- **一致性**：全站无硬编码品牌色值，所有取色经令牌。
- **可切换**：亮/暗主题下两品牌色均在场且角色清晰，切换无硬切、无不可读组合。
- **可维护**：新增界面只需引用 `--color-*` 令牌，无需关心具体色值。
